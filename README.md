# 🗓️ DayCount

**Track the days that matter.**

DayCount is a beautiful, modern, and fully responsive countdown web application. It calculates the exact time remaining until your target date, featuring a sleek glassmorphism UI, a live progress ring, and persistent storage.

## ✨ Features

- **Live Countdown:** Updates every second (Days, Hours, Minutes, Seconds).
- **Persistent Storage:** Uses `localStorage` so your countdown survives page refreshes and browser restarts.
- **Progress Visualization:** Beautiful animated SVG ring showing percentage complete.
- **Responsive Design:** Looks perfect on desktop, tablet, and mobile.
- **Zero Dependencies:** No frameworks, no build steps, no external libraries.
- **Dark Glassmorphism UI:** Premium, modern aesthetic with smooth micro-interactions.

## 🛠️ Tech Stack

- **HTML5** (Semantic structure)
- **CSS3** (Custom properties, Flexbox/Grid, Animations)
- **Vanilla JavaScript** (ES6+)
- **LocalStorage API** (Data persistence)

## 🚀 Quick Start

No installation or build process required.

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.

```bash
# Or simply run with a local server if you prefer:
npx serve .
```
